# ASTROGURU

ASTROGURU is an Online Astro Consultation and Service Management System developed for users to connect with astrologers, book consultations, manage services, and handle user interactions through a modern web platform.

## 🚀 Features

- User Authentication & Authorization
- Admin Dashboard
- Astrologer Management
- Consultation Booking System
- Service Management
- Secure MongoDB Database Integration
- Responsive UI
- API Integration
- Real-Time Data Handling

## 🛠️ Tech Stack

Frontend:
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

Backend:
- Node.js
- Express.js

Database:
- MongoDB

## 📂 Project Setup

### 1. Clone Repository

```bash
git clone https://github.com/your-username/astroguru.git
````

### 2. Install Dependencies

```bash
npm install
```

### 3. Setup Environment Variables

Create a `.env` file in the root directory and add the required variables.

### 4. Run Development Server

```bash
npm run dev
```

Project will run on:

```bash
http://localhost:3000
```
